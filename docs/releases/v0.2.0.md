# nfscarbon-nx v0.2.0 (preview)

Performance and sound update. Still a work in progress.

**Needs your own copy of Need for Speed: Carbon for Xbox 360, USA edition** (`.iso` or the extracted disc with
`default.xex`). No game files are included.

## Files

- `nfscarbon.nro`: the port (profile-guided build)
- `nfscarbon.toml`: settings

Install: [README, Install](../../README.md#install-prebuilt-nro). Launch with title takeover (hold R while starting a
game) or a forwarder with a 39-bit address space.

## What changed since v0.1.0

**Speed**
- Profile-guided build (PGO) and the hottest functions grouped at the start of the code: about 25 % faster in the
  heaviest scenes (Race Wars start at ~3700 draws per frame: 20.7 → 25.8 fps).
- Renderer: the vertex arena hash no longer clusters (it caused 1-3 s freezes and slower draws as a race went on);
  NVK draw-path improvements from nfsmw-nx; shader constant writes copied in bulk; cheaper timers.

**Sound**
- The game's audio server is watched: each frame waits briefly for its packet and a stalled packet is rescued.
- XMA decoding in a hybrid mode: the first frames of each stream on the calling thread, the rest on a worker. Fixes
  the silent menu after which a race never loaded.
- Native versions of the audio server's hottest loops (gain sum, filter, resamplers, int16 to float), checked
  bit-exact against the translated code.
- The audio mixer now runs above the renderer (priority 0x2A). Together, the sound gaps at the start of Race Wars
  are about half of what they were.

**Other**
- Slow reads and audio gaps are logged; frames over 100 ms are logged as hitches.
- README: how to make your own PGO build.

## State (Switch Lite, CPU 1683 / GPU 844 / RAM 2133)

| | FPS | Sound |
|---|---|---|
| Normal races, police chases | 28-30 | fine |
| Race Wars, first 20-40 s (3500-5700 draws per frame) | 19-24 | some crackling / slow-down |
| Race Wars after the start | 26-30 | fine |

At 1785 / 921 / 2133 and above the Race Wars start is much better.

## Known issues

- Race Wars start: low frame rate and some broken-up sound while the whole pack is on screen.
- A random one-frame white flash (a stray giant polygon).
- A second, ghost car shadow.
- A short freeze during the race countdown.
- The first race stutters while it compiles pipelines.

## Feedback

Issues with the logs are the most useful thing you can send: `logs/nfscarbon_*.log`, `logs/rex/rex_perfil.log`, and
for a crash `logs/rex/rex_crash.log` plus the Atmosphère crash report. Say which clocks you used.
