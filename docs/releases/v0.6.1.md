Need for Speed: Carbon (Xbox 360) running natively on the Nintendo Switch. A fix release for all seven editions: **Neville's garage cutscene** at the start of the career is fixed.

> **Needs your own copy of Need for Speed: Carbon for Xbox 360**, one of the editions below (a `.iso` or the extracted disc with `default.xex`). No game files are included here.
>
> **Needs an overclock.** The game is CPU-bound and does not run well at the Switch's stock clocks. Everything below was tested at **CPU 1683 / GPU 844 / RAM 2133 MHz** with the fourth CPU core.

## Install

Same as before ([README](https://github.com/Kaays/nfscarbon-nx#install-prebuilt-nro)): the NRO, `nfscarbon.toml` and your disc's files in `game_root/`, in one folder on the SD card, and a [Sphaira](https://github.com/ITotalJustice/sphaira) forwarder with **4 CPU cores** and a **39-bit address space** ([README, fourth core](https://github.com/Kaays/nfscarbon-nx#experimental-the-fourth-cpu-core)). One folder per edition, for example:

```text
sdmc:/switch/nfscarbon-nx-fr/    nfscarbon.nro   nfscarbon.toml   game_root/ (French disc)
sdmc:/switch/nfscarbon-nx-de/    nfscarbon.nro   nfscarbon.toml   game_root/ (German disc)
```

Updating from v0.6.0: replace the NRO only; keep the toml, `game_root/` and your saves.

## What's new since v0.6.0

**Neville's garage cutscene fixed** (all editions)
- After the first police chase of the career, Neville meets you at the garage. With the tuner or the muscle car the camera sits inside your car there, and the screen was covered by flat grey and black shapes, with Neville hidden behind them.
- Cause: the renderer clamped depth instead of clipping at the near plane in every draw, so the parts of the car behind and around the camera were stretched across the screen. It now clips like the Xbox 360 does, and clamps only when the game asks for it.
- The renderer also honours the game's user clip planes now (an Xbox 360 GPU feature that was missing; not used in this scene).

The first start after updating rebuilds the pipeline list once, so the first race may stutter a little more than usual.

## Known issues

- Rare crashes in police chases, seen in the Europe (Nordic) build. The same code is in the other builds; cause not found yet.
- A rare one-frame white flash in long races; once in a while a few black frames at a race start.
- The first race stutters while it compiles pipelines (only the first time).
- In a few in-engine cutscenes, if the frame rate drops below 30, the lips can drift slightly behind the voice.

## Reporting problems

Please [open an issue](https://github.com/Kaays/nfscarbon-nx/issues) and attach `logs/nfscarbon_*.log`, `logs/rex/rex_perfil.log` and, for a crash, `logs/rex/rex_crash.log` from the game's folder, plus `unregistered_targets.txt` if there is one next to the NRO. Say which edition, which clocks, and whether the fourth core was enabled.
