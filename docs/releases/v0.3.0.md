# nfscarbon-nx v0.3.0

Playable with an overclock: sound, videos and cutscenes fixed, and support for the Switch's fourth CPU core.

**Needs your own copy of Need for Speed: Carbon for Xbox 360, USA edition** (`.iso` or the extracted disc with
`default.xex`). No game files are included.

**Needs an overclock.** At stock clocks the game does not run well (CPU-bound). Tested at CPU 1683 / GPU 844 /
RAM 2133 MHz.

## Files

- `nfscarbon.nro`: the port (profile-guided build)
- `nfscarbon.toml`: settings (replace your old one: several defaults changed)

Install: [README, Install](../../README.md#install-prebuilt-nro). Recommended: a HOME Menu forwarder made with
Sphaira with the CPU core count set to **4** ([README, fourth core](../../README.md#experimental-the-fourth-cpu-core)).

## What changed since v0.2.0

**Fourth CPU core**
- The game's threads run on every core the process is given. With a Sphaira forwarder set to 4 cores (or the
  `tools/npdm_core3.py` NPDM patch), the sound at Race Wars starts is clean: from 59-179 lost blocks per 10 s to
  none. Thanks to the player who reported it in #1.

**Videos**
- Cutscene and boss face videos are decoded with FFmpeg's WMV3 decoder (ported from zofo007's NFS-Carbon-NX):
  normal speed, about 10 ms per frame.

**Graphics fixes**
- In-car cutscenes (boss confrontations, Neville's garage): the people behind the car windows no longer disappear.
  The reflection cube is redrawn in full every frame (`carbon_gpu_reflection_faces = 6`) and resolves are always
  copied (`carbon_gpu_skip_redundant_resolves = false`).
- The boss picture-in-picture box runs at full frame rate (`carbon_gpu_mirror_half_rate = false`).
- Vertex cache raised to 256 MiB: it no longer fills up and starts over in crowded races, which made the white
  flash much more frequent.

Turning these shortcuts off costs under 1 FPS.

**Sound and CPU**
- More of the audio server's loops run as native code (ramped mix, mode-1 unpack from NFS-Carbon-NX), checked
  bit-exact against the translated code.
- Optional scene detail setting `nfscarbon_lod_bias` (from NFS-Carbon-NX): below 1.0, fewer draws in crowded
  scenes. Default 1.0 (the game's own).

**Build**
- `nfscarbon_register.cpp` built at -O1: the full build no longer takes over an hour on some machines.

## State (Switch Lite, CPU 1683 / GPU 844 / RAM 2133)

|---|---|---|
| Normal races, police chases | 28-30 FPS | 28-30 FPS |
| Race Wars, first seconds | 24-27 FPS, then 28-30 | 19-24 FPS for 20-40 s, then 26-30 |
| Sound | clean | some popping at Race Wars starts |

## Known issues

- The car's shadow slides behind the car at speed (most visible in Race Wars).
- A rare one-frame white flash in long races; once in a while a few black frames at a race start.
- A short freeze when the player takes control at the start of a race.
- The first race stutters while it compiles pipelines.

## Feedback

Issues with the logs are the most useful thing you can send: `logs/nfscarbon_*.log`, `logs/rex/rex_perfil.log`, and
for a crash `logs/rex/rex_crash.log` plus the Atmosphère crash report. Say which clocks you used and whether the
fourth core was enabled.
