Need for Speed: Carbon (Xbox 360) running natively on the Nintendo Switch. This release fixes the freezes of long career sessions, a crash in police chases, and adds a first, experimental build for the **Europe** edition.

> **Needs your own copy of Need for Speed: Carbon for Xbox 360**, USA or Europe edition (a `.iso` or the extracted disc with `default.xex`). No game files are included here.
>
> **Needs an overclock.** The game is CPU-bound and does not run well at the Switch's stock clocks. Everything below was tested at **CPU 1683 / GPU 844 / RAM 2133 MHz** with the fourth CPU core.

## Files

- `nfscarbon.nro`: USA edition, `Need for Speed - Carbon (USA) (En,Es)`
- `nfscarbon-pal.nro`: Europe edition, `Need for Speed - Carbon (Europe) (En,Nl,Sv,Da,Fi)` (experimental)
- `nfscarbon.toml`: settings, the same for both. **Replace your old one** (new setting `protect_zero`).

Each NRO only runs its own disc. Both builds are profile-guided.

## Install

Same as before ([README](https://github.com/Kaays/nfscarbon-nx#install-prebuilt-nro)): the NRO, `nfscarbon.toml` and your disc's files in `game_root/`, in one folder on the SD card. Any folder works: the game, saves, logs and caches are found next to the NRO. To keep both editions, use one folder each:

```text
sdmc:/switch/nfscarbon-nx-usa/     nfscarbon.nro      nfscarbon.toml   game_root/ (USA disc)
sdmc:/switch/nfscarbon-nx-pal/     nfscarbon-pal.nro  nfscarbon.toml   game_root/ (Europe disc)
```

and a [Sphaira](https://github.com/ITotalJustice/sphaira) forwarder for each NRO with **4 CPU cores** and a **39-bit address space** ([README, fourth core](https://github.com/Kaays/nfscarbon-nx#experimental-the-fourth-cpu-core)). A forwarder remembers the path of its NRO: after moving or renaming an NRO, install its forwarder again.

Updating from v0.3.0: replace the NRO and the toml, keep `game_root/` and your saves.

## What's new since v0.3.0

**No more freezes in long sessions** (USA and Europe)
- Late in a career session the game could freeze at a cutscene, when a boss or crew intro video did not show up, or entering a race (canyon intros) or free roam after a race. It ran out of memory when it started a new thread. Four fixes, together: finished threads give back their memory, smaller host thread stacks (4 MiB instead of 16), GPU memory in 32 MiB blocks instead of 256, and the game's memory committed in 64 KB granules (fewer kernel mappings). Sessions of 1.5-2.5 hours now run without freezes in our tests.

**Police chase crash** (USA and Europe)
- A police chase after a territory race crashed on one of the game's own checks (it writes to address 0 when an object it expects is missing). `protect_zero = false` in the toml lets the game carry on.

**Europe edition** (experimental)
- A first build for the Europe disc. Its code is the same build of the game with small changes, so the USA function list and all the USA hooks (sound, FFmpeg videos, frame pacing, ring wait, LOD) were carried over by matching the code of the two discs. The game asks for the language at the first start.
- Played for several hours: career with the first three bosses, sprint, circuit, drift, canyon, Race Wars, police chases. About the same speed as USA: 28 FPS median, 20-26 FPS in the heaviest scenes (crowded police chases), clean sound.
- It has had less testing than USA. Please report what you find, with the logs.

**More editions are planned**, each as its own build: the other European discs (French, German, Italian, Spanish), Japan, and the Collector's Editions.

## Performance (Switch Lite, CPU 1683 / GPU 844 / RAM 2133, four cores)

| | USA | Europe |
|---|---|---|
| Normal races, police chases | 28-30 FPS | 28-30 FPS, 20-26 in crowded chases |
| Race Wars, first seconds | 24-27 FPS, then 28-30 | similar |
| Sound | clean | clean |

## Known issues

- Rare crashes in police chases: twice in the Europe build, once already at heat level 1. The same code is in the USA build; cause not found yet.
- Europe: Neville's garage cutscene at the start of the career hides Neville at first. Later cutscenes are fine.
- The car's shadow slides behind the car at speed.
- A rare one-frame white flash in long races; once in a while a few black frames at a race start.
- The first race stutters while it compiles pipelines (only the first time).

## Reporting problems

Please [open an issue](https://github.com/Kaays/nfscarbon-nx/issues) and attach `logs/nfscarbon_*.log`, `logs/rex/rex_perfil.log` and, for a crash, `logs/rex/rex_crash.log` from the game's folder, plus `unregistered_targets.txt` if there is one next to the NRO. Say which edition, which clocks, and whether the fourth core was enabled.
