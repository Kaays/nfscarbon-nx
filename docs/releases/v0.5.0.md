Need for Speed: Carbon (Xbox 360) running natively on the Nintendo Switch. This release adds **video settings inside the game** (Options > Video) and fixes the **car shadow** sliding behind the car.

> **Needs your own copy of Need for Speed: Carbon for Xbox 360**, one of the editions below (a `.iso` or the extracted disc with `default.xex`). No game files are included here.
>
> **Needs an overclock.** The game is CPU-bound and does not run well at the Switch's stock clocks. Everything below was tested at **CPU 1683 / GPU 844 / RAM 2133 MHz** with the fourth CPU core.

## Files

Download the archive for your edition. Each one holds `nfscarbon.nro` (profile-guided build) and `nfscarbon.toml` (settings).

Each NRO only runs its own disc. Not sure which one you have? Compare `sha1sum default.xex` with the table.

## Install

Same as before ([README](https://github.com/Kaays/nfscarbon-nx#install-prebuilt-nro)): the NRO, `nfscarbon.toml` and your disc's files in `game_root/`, in one folder on the SD card, and a [Sphaira](https://github.com/ITotalJustice/sphaira) forwarder with **4 CPU cores** and a **39-bit address space** ([README, fourth core](https://github.com/Kaays/nfscarbon-nx#experimental-the-fourth-cpu-core)). One folder per edition:

```text
sdmc:/switch/nfscarbon-nx-usa/     nfscarbon.nro   nfscarbon.toml   game_root/ (USA disc)
sdmc:/switch/nfscarbon-nx-pal2/    nfscarbon.nro   nfscarbon.toml   game_root/ (Europe disc)
sdmc:/switch/nfscarbon-nx-pal/     nfscarbon.nro   nfscarbon.toml   game_root/ (Europe (Nordic) disc)
```

Updating from v0.4.7: replace the NRO and the toml (the new toml has the new settings), keep `game_root/` and your saves.

## What's new since v0.4.7

**Video settings in the game** (all editions)
- The game's **Options > Video** screen now has these rows next to Brightness. Change them with left/right, as with the game's own options:

| Row | Choices | Default |
|---|---|---|
| Motion Blur | On / Off | On |
| Anti-Aliasing | Off / On | Off |
| Scene Detail | Full / Reduced | Reduced |
| Car Reflections | Full / Reduced / Off | Full |
| Anisotropic Filtering | Off / 2x / 4x / 8x / 16x | 4x |
| Resolution (Restart) | Ultra Performance (360p) / Performance (480p) / Balanced (600p) / Quality (720p) / Ultra Quality (1080p) | Quality (720p) |
| Rear-View Mirror | Full Rate / Half Rate | Full Rate |

- Your choices are saved in `nfscarbon_options.txt` next to the NRO and win over the toml. Everything applies at once except Resolution, which needs a restart.
- Motion Blur Off removes the speed and NOS blur and keeps everything else (the pause screen and cutscenes look as before). Thanks to zofo007 for the request ([#5](https://github.com/zofo007/NFS-Carbon-NX/issues/5)).
- What they cost on a Switch Lite: Scene Detail Full about 2-3 FPS in crowded scenes, Anti-Aliasing about 1-2 FPS, Motion Blur and Anisotropic Filtering nothing measurable. The game is CPU-bound, so resolutions below 720p do not raise the frame rate in races; 1080p runs at about 14-15 FPS.

**Car shadow fixed** (all editions)
- The car's shadow slid behind the car at speed, most of all at Race Wars starts. The game rewrites the shadow every frame, but the renderer's vertex cache checked unchanged data only every 4 frames, so the shadow was drawn where the car had been a few frames earlier (worse the lower the frame rate). The cache now checks every frame, and checks data the game has changed before on every draw. No cost in frame rate.

**Other fixes**
- A freeze in a menu (seen on the Challenge Series screen): the game's audio mixer could spin at full CPU and starve the rest. It is now lowered for a moment when that happens.
- `logs/rex/rex_perfil.log` keeps the last five sessions (`rex_perfil_1.log` to `rex_perfil_4.log` are the older ones).

**Next**: the French, Italian, German and Spanish discs.

## Known issues

- Rare crashes in police chases, seen in the Europe (Nordic) build. The same code is in the other builds; cause not found yet.
- Europe (Nordic): in Neville's garage cutscene at the start of the career, Neville stays hidden with the muscle car (with the tuner only for a moment).
- A rare one-frame white flash in long races; once in a while a few black frames at a race start.
- The first race stutters while it compiles pipelines (only the first time).

## Reporting problems

Please [open an issue](https://github.com/Kaays/nfscarbon-nx/issues) and attach `logs/nfscarbon_*.log`, `logs/rex/rex_perfil.log` and, for a crash, `logs/rex/rex_crash.log` from the game's folder, plus `unregistered_targets.txt` if there is one next to the NRO. Say which edition, which clocks, and whether the fourth core was enabled.
