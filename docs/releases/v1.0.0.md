Need for Speed: Carbon (Xbox 360) running natively on the Nintendo Switch. **Version 1.0.0**: a big performance release, playable at the Switch's stock clocks at 540p and at a steady 30 FPS in races with a moderate overclock, for all nine editions.

> **Needs your own copy of Need for Speed: Carbon for Xbox 360**, one of the editions below (a `.iso` or the extracted disc with `default.xex`). No game files are included here.

## Install

Same as before ([README](https://github.com/Kaays/nfscarbon-nx#install-prebuilt-nro)): the NRO, `nfscarbon.toml` and your disc's files in `game_root/`, in one folder on the SD card, and a [Sphaira](https://github.com/ITotalJustice/sphaira) forwarder with **4 CPU cores** and a **39-bit address space** ([README, fourth core](https://github.com/Kaays/nfscarbon-nx#experimental-the-fourth-cpu-core)). One folder per edition, for example:

```text
sdmc:/switch/nfscarbon-nx-fr/    nfscarbon.nro   nfscarbon.toml   game_root/ (French disc)
sdmc:/switch/nfscarbon-nx-de/    nfscarbon.nro   nfscarbon.toml   game_root/ (German disc)
sdmc:/switch/nfscarbon-nx-collector_usa/   nfscarbon.nro   nfscarbon.toml   game_root/ (Collector's Edition, USA)
```

Updating from v0.7.0: replace the NRO **and** `nfscarbon.toml` (two defaults changed, see below); keep `game_root/` and your saves. If you set options in Options > Video before, check the Resolution row once: the old "Balanced (600p)" is now "Balanced (540p)".

Only the Collector's Edition (Europe) was played through for this release. The other eight editions run the same code, with every hook found in their own code automatically; each was started and checked briefly.

## What's new since v0.7.0

**Faster**
- The game's frame pacing no longer waits for a 60 Hz vblank after each frame (guest vblank at 1 kHz, `carbon_gpu_vsync = false`): heavy scenes that used to fall from ~28 to 20 FPS now stay near 28.
- The renderer records its Vulkan commands on a thread of its own, reuses texture bindings within a frame and across frames, checks and copies only the changed parts of vertex buffers, and lets NVK use ZCULL (fast depth rejection) on depth buffers.
- Shader translation: the Xbox 360's zero-safe multiply is written in the form the NVK compiler turns into a single instruction, and shaders with loops get structured loops.
- The frame preparer, the renderer threads and the audio mixer are pinned to their own cores by default.
- Native versions of hot game code: the vector math the game uses everywhere (point transform, 4x4 matrix product) and the audio server's loops (voice parameter graph, ADPCM decoder, filter, scale).

**Sound**
- Much less crackle when the frame rate drops: the mixer decodes up to two XMA packets per stream itself instead of waiting for the decoder thread, and the audio output keeps a 16-frame queue.

**Options > Video**
- New **FPS Limit** row (30 / 40 / 60).
- Resolution: **Balanced** is now **540p** (was 600p): 360p, 480p, 540p, 720p, 1080p.

**Fixes**
- A thin black line in the menus at resolutions below 720p is gone.

**Settings (`nfscarbon.toml`)**
- `carbon_gpu_vsync = false` (new default, see above).
- `nfscarbon_switch_ram_1600 = true`: the NRO no longer pulls the RAM back to 1331 MHz when an overclock tool raises it. With an overclock tool you can also set `nfscarbon_switch_gpu_mhz = 0`, and the NRO leaves every clock to the tool.

## Known issues

- A one-frame white flash in races: now and then a nearby AI car lights the road and the scenery for one frame, about every 3 seconds while it is right behind or beside you. It may be the game's own effect; still being looked into.
- The road texture can disappear for 1-2 seconds and then come back.
- A short freeze when the player takes control at the start of a race.
- The first race stutters while it compiles pipelines (only the first time).

## Reporting problems

Please [open an issue](https://github.com/Kaays/nfscarbon-nx/issues) and attach `logs/nfscarbon_*.log`, `logs/rex/rex_perfil.log` and, for a crash, `logs/rex/rex_crash.log` from the game's folder, plus `unregistered_targets.txt` if there is one next to the NRO. Say which edition and which clocks.
