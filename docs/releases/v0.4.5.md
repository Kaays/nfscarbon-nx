Need for Speed: Carbon (Xbox 360) running natively on the Nintendo Switch. This release adds the **Europe** edition, the English-only European disc.

> **Needs your own copy of Need for Speed: Carbon for Xbox 360**, one of the editions below (a `.iso` or the extracted disc with `default.xex`). No game files are included here.
>
> **Needs an overclock.** The game is CPU-bound and does not run well at the Switch's stock clocks. Everything below was tested at **CPU 1683 / GPU 844 / RAM 2133 MHz** with the fourth CPU core.

## Files

Download the archive for your edition. Each one holds `nfscarbon.nro` (profile-guided build) and `nfscarbon.toml` (settings).

| Archive | Edition | Disc | `default.xex` SHA-1 |
|---|---|---|---|
| `nfscarbon-nx-usa.zip` | USA | `Need for Speed - Carbon (USA) (En,Es)` | `75ed29cfde2af689fb4f0615d743c07cab31b9da` |
| `nfscarbon-nx-pal2.zip` | **Europe** (new) | `Need for Speed - Carbon (Europe)`, English only | `1092188030919ba25994094dad0dfc8c15a14dc8` |
| `nfscarbon-nx-pal.zip` | Europe (Nordic) | `Need for Speed - Carbon (Europe) (En,Nl,Sv,Da,Fi)` | `90c2181d9f67612b017da1ce23b07d735e2d3f58` |

Each NRO only runs its own disc. There are two European discs: the one called **Europe (Nordic)** here is the v0.4.0 "Europe" build (English, Dutch, Swedish, Danish, Finnish). Not sure which one you have? Compare `sha1sum default.xex` with the table.

## Install

Same as before ([README](https://github.com/Kaays/nfscarbon-nx#install-prebuilt-nro)): the NRO, `nfscarbon.toml` and your disc's files in `game_root/`, in one folder on the SD card, and a [Sphaira](https://github.com/ITotalJustice/sphaira) forwarder with **4 CPU cores** and a **39-bit address space** ([README, fourth core](https://github.com/Kaays/nfscarbon-nx#experimental-the-fourth-cpu-core)). One folder per edition, for example:

```text
sdmc:/switch/nfscarbon-nx-pal2/    nfscarbon.nro   nfscarbon.toml   game_root/ (Europe disc)
```

Updating from v0.4.0: replace the NRO, keep the toml, `game_root/` and your saves. For USA and Europe (Nordic) nothing changed in the game code.

## What's new since v0.4.0

**Europe edition**
- The English-only European disc, made the same way as Europe (Nordic): the function list and all the hooks (sound, FFmpeg videos, frame pacing, ring wait, LOD) carried over from USA and Europe (Nordic) by matching the code. One function needed its bounds set by hand: its switch table lands on a 64 KB boundary in this disc and the code generator cut the function there (the game crashed at the first video).
- Played for over two hours: career, cutscene videos, races, police chases. No crash, no freeze. About the same speed as the other editions: 28-29 FPS median, 23-26 FPS in the heaviest scenes, clean sound.

**Next**: the French, Italian, German and Spanish discs. Each has its own `default.xex`, and their manifests are in progress. Then the Collector's Editions and Japan.

## Known issues

- Rare crashes in police chases, seen in the Europe (Nordic) build. The same code is in the other builds; cause not found yet.
- Europe (Nordic): in Neville's garage cutscene at the start of the career, Neville stays hidden with the muscle car (with the tuner only for a moment).
- The car's shadow slides behind the car at speed.
- A rare one-frame white flash in long races; once in a while a few black frames at a race start.
- The first race stutters while it compiles pipelines (only the first time).

## Reporting problems

Please [open an issue](https://github.com/Kaays/nfscarbon-nx/issues) and attach `logs/nfscarbon_*.log`, `logs/rex/rex_perfil.log` and, for a crash, `logs/rex/rex_crash.log` from the game's folder, plus `unregistered_targets.txt` if there is one next to the NRO. Say which edition, which clocks, and whether the fourth core was enabled.
